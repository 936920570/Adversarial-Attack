# Audio Adversarial Attack

This script generates short, segment-based adversarial examples by injecting optimized perturbations into a carrier music track at a specified start time.

The implementation is in `short_attack_digital.py` and `short_attack_physical.py`.

`find_best_masking_segment.py` and `find_best_masking_segment2.py` use MPEG-1 Psychoacoustics Model 1 and MPEG-1 Psychoacoustics Model 2 respectively, to select a masking-aligned carrier.

## Installation
1. Clone this repository

2. Create a virtual conda environment with Python 3.9

3. Install dependencies

```bash
pip install -r requirements.txt
```
(requirements.txt generated by gemini 3 pro.)

## Usage

### Prepare inputs

1. Configure your ASR cloud credentials in `account.py` (and related files under `cloud_decode/`).

2. Create a `music` directory and put carrier audio files inside it:
     - WAV format
     - 16 kHz sample rate

3. Create a `command` directory and put target command audios inside it:
     - WAV format
     - 16 kHz sample rate
     - Filename is used to derive the target text (underscores `_` are converted to spaces)

### Finding Best Masking Segments (Optional)

Before running the attack, you can use `find_best_masking_segment.py` to identify music segments that naturally provide the best psychoacoustic masking for your command audio. This tool analyzes carrier music using the MPEG/ISO psychoacoustic masking model.

**Quick Usage:**

```bash
python find_best_masking_segment.py <audio_dir> <command_audio>
```


**Output:**
- Audio files: `rank{N}_{original_filename}.wav`
- Visualizations: `rank{N}_visualization.png` showing masking curves and frame-by-frame coverage
- Statistics: `statistics.txt` with detailed analysis results

### Command

```bash
python short_attack_physical.py [options]
```
python short_attack_physical.py --speech-file-path command/open_the_door.wav --music-file-path ./music --sample-num 1 --attack-target openai --start-second 1

Use the same command about `short_attack_digital.py`



## Outputs

Successful adversarial examples are saved under:

```
physical_samples/<command_name>/<attack_target>/
```

The output filename includes quality metrics:

```
<command>_<music>_<start_time>_<target>_SNR<...>_segSNR<...>.wav
```

Example:

```
open_the_door_pop_music_0_aliyun_SNR15.234_segSNR12.456.wav
```

Notes:
- The script will also write an intermediate WAV in the working directory during evaluation.
- If `--start-second` exceeds the available range, the script clamps it to the latest feasible position.

## What the script does (high level)

1. Loads the command audio and carrier music (16 kHz mono)
2. Computes STFT and optimizes a non-negative, smoothed perturbation (with a 200–7000 Hz frequency mask)
3. Reconstructs waveform (GLA/ISTFT-based)
4. Sends audio to the chosen cloud ASR and checks whether the command phrase appears in the transcript
5. On success, computes SNR and weighted segmental SNR (50 ms) and saves the final WAV
